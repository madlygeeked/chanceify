# Keyboard shortcuts

Press **T** (or open **Keyboard shortcuts** from the menu under your picture)
to see every key. Click a key to change it, right-click to clear it. The list
floats, so you can still move and resize the window while it is open.

You can export your keys to a file, import them again, or save them as the
default for everyone.

Starting keys:

| Key | Does |
|-----|------|
| Esc | Leave full screen and go to the top of the playlist that is playing |
| X | Show the queue and lyrics together (press again to close both) |
| V | Full-screen visualizer |
| B | Visualizer settings |
| C | Full-screen lyrics |
| Z | Views |
| M | Mini player |
| T | This list |

In the shortcuts list (press T) click a key to change it. Shift and Ctrl can go with any key, for example Ctrl+Up for volume up or Ctrl+Z for undo. Right-click a key to clear it.

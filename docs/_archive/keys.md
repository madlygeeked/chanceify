# keys

press **t** to see every key. click a key to change it. right-click clears it. shift and ctrl can go with any key. export, import, or save your set as the default.

| key | does |
|-----|------|
| esc | leave full screen |
| x | queue and lyrics together |
| v | full-screen visualizer |
| b | visualizer settings |
| c | full-screen lyrics |
| z | views |
| m | mini player |
| t | this list |
| ` | default view |
| home | calm mode |

**queue.** ctrl+click a song adds it to the queue. shift+ctrl+click plays it next. alt+click picks several rows.

**bass jump.** press it on the beat. the screen shakes and flashes in the cover's colour.
